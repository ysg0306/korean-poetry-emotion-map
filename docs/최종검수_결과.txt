2. 이번 보완과 기술 검수
- 모바일 소개·서가·본문 높이를 조정하고, 긴 출처 설명과 레이더는 접어서 펼쳐 보도록 했다.
- 본문 전체는 내부 스크롤로 보며 삭제하거나 축약하지 않았다.
- 레이더를 행별 차트 옆의 별도 패널로 옮겨 필수 정보를 먼저 보여 준다.
- 레이더 연결선은 사용자의 마지막 요청대로 0%도 중앙에 포함하는 원래 방식이다.
- 행별 차트는 정수 세로축·행 번호·범례가 있고, 모바일 높이가 바뀌어도 막대 비율이 맞는다.
- '그림자라고요'의 어미에서 '고요'를 평온으로 세던 오탐을 제외했다. 사전 항목 수는 유지했다.
- 분석 결과에 dominant를 추가하고 동률 표현용 dominantKeys도 유지했다.
- CSS와 모든 JavaScript 파일에 내용 해시 주소를 붙여 예전 캐시가 섞이는 문제를 줄였다.

390×844 모바일: 15편의 필수 정보 끝(행별 차트 포함)이 문서 시작에서 약 1634px 이내.
처음부터 두 화면 높이(1688px) 안이므로 한 화면 높이만큼 스크롤하면 확인할 수 있었다.
4개 메뉴 모두 페이지 콘텐츠 폭 375px = 뷰포트 콘텐츠 폭 375px, 가로 넘침 없음.
표·서가·긴 차트는 자기 영역에서 가로로 이동한다. 더 짧은 화면이나 글자 확대 시 추가 스크롤 가능.
PC 1280×900: 필수 정보 끝 약 1547px, 두 화면 높이 안. 레이더는 기본 펼침.
15편 전환의 동기 DOM 갱신+레이아웃 최대: 로컬 13.6ms / 공개 웹앱 92.5ms. 브라우저 제어 통신 시간과 구분해 측정했다.
이 수치는 최초 네트워크 로드나 모든 기기의 실제 페인트 시간을 보증하지 않는다.

T-01~T-06: 15편 전환, 비율 합계, 무감지·빈 입력 안내, 추천 이동·갱신, 모바일 메뉴 확인.
직접 입력 '외로움 / 위로'는 슬픔 50%, 평온 50%와 행별 결과를 표시.
HTML 형태 입력은 텍스트로 표시되고 script 요소를 만들지 않음. Enter로 차트 근거 확인 가능.
출처 상세와 레이더의 접기·펼치기, 긴 본문의 마지막 행 접근도 확인.
T-07: 「사슴」 공유마당 본문 이미지를 다시 보고 2연 8행과 단어를 대조했다.
한자 병기를 한글로 읽는 차이를 알리며, 본문과 행·연 구분을 유지했다.
15편 전체는 기존 대조 기록과 현재 행·연 수·미처리 자모 검사도 다시 확인했다.
모든 초간본을 완전히 교감했다거나 문학적 해석에 유일한 정답이 있다고 주장하지 않는다.

3. 감점과 평가 기준
저작권 선정 위반: 과제의 사망 연도 기준을 넘는 시인 없음.
주소 오류: 공개 Pages 앱 확인, 최종 푸시 후 최신 화면 재확인.
비밀 정보: 현재 파일과 Git 이력의 대표 패턴 검사에서 발견되지 않음. 모든 비밀의 절대 부재 보증은 아님.
무출처 복제: 본문·참고 해설·예시 저장소·AI 도구 사용 내역에 출처와 사용 부분 표시.
40점 감정 분석: 범주·사전·해석·검증 자료 있음. 해석 깊이와 타당성의 점수는 평가자 판단.
15점 시 데이터: 수록 수·새 작품·선정 조건·출처 확인. 현대 표기 판본 차이 공개.
25점 기능: 필수 5종과 기본 5종 및 차트 수치·근거·이동 확인.
10점 배포·문서: 공개 주소와 README 6항목 있음.
10점 사용성·코드: 모바일·예외 처리·생성/검사 도구 보완.
확장 기능은 선택 사항이며 가산점 +5를 확보했다고 주장하지 않는다.
