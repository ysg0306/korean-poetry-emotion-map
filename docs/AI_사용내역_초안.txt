AI 도구 사용 내역 — README 작성용 초안

사용 도구: ChatGPT(Codex)

사용한 부분
- 웹앱 화면과 감정 사전 분석 코드 작성 및 수정 보조.
- 시 본문을 제공하는 공개 자료 탐색과 현대 표기 대조 보조.
- 15편의 주제와 작품 해석 초안 작성.
- 실제 분석 코드 실행 결과를 이용한 문학적 검증 사례 3건 정리.
- 「통곡」의 특정 부정 구문을 처리하는 예외 규칙 작성과 코드 검사.

이번 해석과 검증의 처리 방식
- 개인 경험이나 학생이 직접 수행한 검토를 지어내어 쓰지 않았다.
- 해석은 수록 본문을 근거로 구성하고, 외부 해설을 참고한 4편에는 참고 링크를 붙였다.
- 검증 수치는 실제 JavaScript 분석 엔진으로 계산했다.
- 코드 검사와 브라우저 검사는 작성 지원 과정에서 실행한 확인 작업이다.
- 학생이 시구와 해석을 직접 읽고 검토·수정한 범위는 실제 수행 후 추가로 기록해야 한다.
- 해석 초안은 하나의 가능한 읽기이며 문학적 의미의 유일한 정답으로 두지 않았다.

제출 전에는 위 사용 범위와 실제 검토한 내용을 바탕으로 README의 AI 사용 내역을 작성한다.
