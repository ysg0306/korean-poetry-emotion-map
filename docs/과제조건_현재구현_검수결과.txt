최종 판정: 제출 조건 전체 충족 아님. 기능 시제품이며 제출 전 보완이 필요하다.

1. 제출 체크리스트

[충족] 시 15편, 예시 외 새 작품 5편 이상

  수록 시인 8명 모두 지시서의 예시 시인 6명과 달라 새 작품은 15편이다.

[수치 기준 충족] 모든 시인 사망 연도 1962년 이전
  데이터의 가장 늦은 사망 연도는 1961년이다.
  따라서 지시서의 '1962년 이전'과 기술명세서의 '1962 이하'를 모두 만족한다.
  이 판정은 과제의 수치 조건에 대한 판정이며, 모든 판본의 이용 조건과 본문 정확도
  대조를 완료했다는 뜻은 아니다. 생몰년 근거는 선정 JSON과 기존 검증 기록에 있다.

[표기 충족 / 정확도 최종 대조 미완료] 15편 모두 본문 출처 표기
  15편 모두 source/sourceUrl이 있고 화면의 출처 링크도 표시된다.
  옛한글 조합 문제는 고쳤고 자동 검사도 통과했다.
  그러나 모든 시를 인쇄 원문과 글자·행·연 단위로 교감한 기록은 없다.
  일부 전사 기록에 초간 지면과의 최종 대조 미완료가 명시돼 있다.
  출처가 있다는 사실과 본문이 정확하다는 사실을 구분해야 한다.

[데이터 충족 / 공개 설명 보완] 감정 범주 6~10개와 정의
  8개 범주이며 모두 한 문장 정의가 있다.

                희망 15, 분노 14, 불안 14, 평온 17 (총 126).

  정의는 lexicon.js와 개발 명세서에 있으나 앱 화면에는 정의 설명이 없고 README도 없다.

[미충족] 시마다 감정 비율·행별 감정·지배 정서·해석
  비율·행별 근거·계산된 지배 정서는 15편 모두 표시된다.

2. 실제 실행 결과

자동 검사: node tools/check_preview_data.cjs 통과.
- 15편의 ID·선정 순서와 본문 준비 상태 확인.
- 미처리 조합형 한글과 대체 문자 없음.
- 감정 비율 벡터 합계 1, 강조 구간 165곳이 실제 문자열과 일치.
- 위로·외로움·싸늘한 이마/먼지·분로·압흐다고 등 보완 표현 확인.
- 방향의 '위로 올라간다', 닭의 울음, 비웃지 등의 지정 오탐 제외 확인.

실제 브라우저 검사: ChatGPT 내장 브라우저 localhost.
- 15편을 각각 선택해 제목·본문·밑줄·출처·비율 갱신 확인.
- 화면 비율 합계 100.0~100.2%로 지시서의 반올림 허용 범위에 들어감.
- 추천 1위 클릭: 「남으로 창을 내겠소」로 실제 이동 확인.
- 비교표: 작품 15행, 헤더 포함 9열, 감정 값 120개 확인.
- 빈 입력: 입력 요청 표시.
- '연필 책상': 무감지 안내 표시.
- '외로움\n위로': 슬픔 50%, 평온 50%, 2개 행 결과와 추천 표시.
- HTML 형태 입력: HTML 요소로 실행되지 않고 텍스트로 표시됨.

테스트가 통과했다는 것은 지정한 동작에 대한 판정이다.
자연어의 모든 문맥을 정확하게 이해하거나 문학적 해석이 검증됐다는 뜻은 아니다.

3. 화면·비기능 요구사항

[충족 범위] 휴대폰 폭 가로 넘침
  390×844 뷰포트 설정에서 세로 스크롤바 제외 콘텐츠 폭은 375px였다.
  시 읽기·전체 비교·내 시 분석 모두 body.scrollWidth=clientWidth=375px.
  표와 서가는 자기 영역 안에서 가로로 이동한다.

[보완] 필수 정보를 첫 화면 또는 한 번의 스크롤로 표시
  모바일 첫 작품 기준 본문 영역 시작 약 728px, 분석 영역 시작 약 1652px,
  비율 막대 시작 약 1818px, 막대 끝 약 2003px, 행별 차트 시작 약 2375px였다.
  화면 높이 844px에서 비율 전체와 행별 결과까지 보려면 한 화면 높이 이상을
  더 내려야 하므로 기술명세서 6장의 첫 화면 기준에 맞추기 어렵다.
  긴 출처·전사 설명을 접을 수 있게 하고 분석 요약 배치를 앞당기는 것이 필요하다.

[미확인] 최신 Chrome·Edge·Safari, 실물 휴대폰, 실제 Pages 하위 경로.
[미확인] 1초 갱신 성능의 정밀 측정. 자동화 왕복 시간은 렌더 시간과 구분하지 못하므로
         그 값으로 성능 통과 또는 실패를 단정하지 않았다.
[보완] '밤기차에 그대를 보내고'의 장 번호 I/II/III/IIII도 분석 행으로 센다.
       현재 40행 중 본문은 36행이므로 장 번호는 별도 구획으로 분리하는 것이 적절하다.
[보완] 기술명세서 Emotion.k는 현재 내부 데이터에서 key라는 이름으로 구현돼 있다.
       앱 내부는 일관되지만 명세 필드명과의 대응을 문서화하거나 맞추면 좋다.

4. 배점 관점의 우선순위

1순위: 15편 주제와 3문장 이상 해석 완성 (감정 분석 40점 및 필수 F-05).
2순위: 실제 작품 불일치 검증 3건 작성, 사전 변경과 남은 한계 기록.
3순위: 차트 축·눈금, 감정 정의 공개, 모바일 분석 요약 배치 보완.
4순위: 원문 정확도·행/연 구분 최종 대조, README 6항목 작성.
5순위: 루트 배포 구조 준비, GitHub 공개 저장소와 Pages 배포, PC·실물 휴대폰 확인.

확장 기능은 선택 사항이다. 감정 이미지·PCA·가중치가 없다는 이유만으로
필수 조건 미충족이라고 판정하지 않았다. 예상 점수는 평가자 판단이므로 산정하지 않았다.
과제는 학생이 해석과 검증 사례를 직접 검토하고 고쳐 쓰도록 요구한다.
학생의 실제 검토 여부와 AI 사용 부분은 README에 사실대로 기록해야 한다.
